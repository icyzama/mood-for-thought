# Mood for Thought

**Mood for Thought** is an AI-assisted creative direction and visual inspiration app for branding designers. It helps turn a rough brief into several distinct directions that a designer can compare, refine, and develop into a moodboard.

## How it works

1. Enter a branding idea or creative brief.
2. Explore three suggested directions, each with a rationale, mood, palette, typography style, and visual approach.
3. Choose a direction and refine it with feedback.
4. Gather references and assets in a moodboard.

Visitors can explore an idea before signing in. An account is needed to save projects and continue on another device.
